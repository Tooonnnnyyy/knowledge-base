## English

### Use each resource to answer a design question

This reading list connects Apple's official materials to concrete outputs. Links and session identities were checked on October 13, 2026. Older videos remain useful for methods; consult current HIG pages for current components and platform behavior.

![A learning route connects principles to layout and visual design, then to prototyping, review and an evidence-based design decision.](https://tooonnnnyyy.github.io/knowledge-base/media/apple-hig/learning-path.svg)

*Original study map. Follow the question you need to answer rather than watching every session in sequence.*

Exercise: make the smallest interactive model that lets someone try one uncertain behavior. Treat the session as a method reference rather than a current visual kit.

### Turn a reference into connected knowledge

Use this note shape: **source → principle → a concrete example → design decision → evidence or open question → related concept**. Keep a source statement separate from an interpretation and a result observed in testing. [[designing-learning-systems|Connected learning]] explains how to keep these notes focused and retrievable.

## 中文

### 带着问题使用资源

这份索引将 Apple 官方资料连接到可以完成的小产物。链接与课程身份核对日期为 2026 年 10 月 13 日。旧视频适合学习方法，当前组件和平台行为应以最新 HIG 为准。

### 先看四个入口

1. **[Principles of great design · WWDC26](https://developer.apple.com/videos/play/wwdc2026/250/)**：配合 [[apple-human-interface-guidelines|设计原则]]，练习解释一个界面中的原则取舍。
2. **[Design foundations from idea to interface · WWDC25](https://developer.apple.com/videos/play/wwdc2025/359/)**：配合 [[apple-design-workflow|工作流]] 和 [[apple-adaptive-layout|布局]]。章节为 01:11 结构、04:55 导航、08:19 内容、13:28 视觉设计。练习把一个产品的功能去重并重新分组。
3. **[Get started with Dynamic Type · WWDC24](https://developer.apple.com/videos/play/wwdc2024/10074/)**：配合 [[apple-accessible-visual-design|可访问的视觉设计]]，比较默认字号与放大字号下的重排需求。
4. **[60-Second Prototyping · WWDC17](https://developer.apple.com/videos/play/wwdc2017/818/)**：用最小交互原型回答一个尚不确定的问题。方法可以参考，视觉组件应重新核对。

### 官方工具入口

- [Apple Design Resources](https://developer.apple.com/design/resources/)：按目标平台选择官方 UI kit、Figma/Sketch 模板和图标模板。
- [Fonts](https://developer.apple.com/fonts/) 与 [SF Symbols](https://developer.apple.com/sf-symbols/)：研究系统字体与图标；具体使用方式需符合资源所附条款。
- [Design Pathway](https://developer.apple.com/design/get-started/)：Apple 官方入门路线。
- [HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[Foundations](https://developer.apple.com/design/human-interface-guidelines/foundations)、[Components](https://developer.apple.com/design/human-interface-guidelines/components)：在作出具体设计决策时查询。
- [What's new in design](https://developer.apple.com/design/whats-new/)：复用旧资料前检查更新。

### 把观看变成可连接的知识

每条学习笔记可以按 **来源 → 原则 → 具体例子 → 设计决策 → 证据或未解决问题 → 相关概念** 整理。明确区分官方表述、个人推导与测试结果。[[designing-learning-systems|连接式学习]] 说明如何让这些内容长期可检索。
