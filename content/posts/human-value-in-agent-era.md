# Human Value in the Agent Era

## English

As agents become better at routine execution, the scarce part of work moves upstream. People still need to choose what matters, notice weak evidence, decide what should remain under human control, and give a result a coherent direction.

This does not make implementation less important. It changes the relationship between implementation and judgment. A strong builder can move between a user need, a system boundary, a prototype, and a test that reveals whether the idea deserves more work.

The useful question is not whether a tool can do a task. It is whether the task should be automated, what evidence is required, and how a person can recover when the system is wrong.

## 中文

当 agent 越来越擅长重复执行，稀缺部分会向上游移动。人仍然需要选择什么重要、识别证据是否薄弱、决定哪些事情必须由人控制，并让结果拥有一致的方向。

这并不意味着实现变得不重要，而是实现和判断之间的关系发生了变化。好的 builder 能在用户需求、系统边界、原型和验证实验之间切换。

真正有用的问题不是工具能不能完成某个任务，而是这项任务是否应该自动化、需要什么证据，以及系统出错时人如何恢复。
